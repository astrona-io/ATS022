# Configure volume types, access modes and reclaim policies

This section covers configure volume types, access modes and reclaim policies. You will study Volume Lifetime, Access And Reclaim. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Compare ephemeral and persistent volume lifetimes.
- Interpret access and volume modes.
- Explain application concurrency limits.
- Predict reclaim and recovery consequences.
